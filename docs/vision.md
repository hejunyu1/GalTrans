# GalTrans 产品愿景

## 目标

GalTrans 最终是一套面向个人汉化者和汉化组的本地优先视觉小说本地化工作台。它帮助用户
安全提取文本、恢复剧情上下文、生成和审阅译文、检查格式与一致性，并为受支持的引擎生成
可验证的翻译资源或补丁。

它不是“让模型直接改游戏文件”的工具。游戏资源处理必须由确定性程序完成，模型只参与
语言理解、翻译建议、风格调整和语义质检。

## 最终能力方向

- 通过插件支持多个视觉小说引擎，首个引擎为 Ren'Py。
- 建立角色、称谓、术语、场景、路线和上下文模型。
- 支持云端与本地模型，并提供缓存、重试、费用和隐私控制。
- 提供初译、润色、一致性检查和低置信度人工复核流程。
- 保护变量、文本标签、跳转、控制符、编码和原始文件。
- 支持增量处理、差异审阅、撤销和可追踪的操作记录。
- 检查漏译、错位、术语冲突、文本溢出和脚本损坏。
- 后期支持图片文字、字体、UI 和有限的游戏内自动验证。
- 为得到授权的项目生成翻译资源、测试包或差分补丁。

## 目标用户

- 想汉化个人或开源视觉小说的个人用户。
- 需要减少重复劳动的汉化组。
- 希望为自己的游戏添加中文版本的独立开发者。

用户不一定是程序员，因此关键操作应提供清晰提示、可恢复默认值和可视化审阅能力。

## 非目标

- 不承诺无人参与即可达到优秀人工汉化的文学质量。
- 不以破解 DRM、绕过加密或未经授权分发游戏内容为目标。
- 不承诺一个通用解析器自动支持所有私有或魔改引擎。
- 不让语言模型直接拥有不受校验的文件写入权限。
- 不在早期版本同时支持解包、图片修复、多人协作和所有引擎。

## 成功标准

对一个明确支持且得到授权的项目，用户能够完成：

```text
导入 → 提取 → 上下文分析 → 翻译 → 审阅 → 质检 → 安全导出 → 实机验证
```

每一步可以中断、恢复和审计；任何自动化失败都不会破坏原始游戏。
