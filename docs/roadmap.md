## 后续

### V0.2：Ren'Py 可运行闭环

- 下载并接入 Ren'Py SDK
- 与官方翻译模板交叉验证
- 生成不覆盖原文件的中文翻译目录
- lint、编译、启动和基础显示验证

### V0.3：翻译工作流

- 模型服务抽象、请求缓存和断点续传
- 角色卡、术语表和场景上下文
- 翻译结果结构与标记校验
- 确定性质量检查和低置信度列表

### V0.4：审阅工作台

- 本地 API 与 Web UI
- 原文、译文、上下文和问题并排审阅
- 批量接受、退回、重试和差异检查

### V0.5：扩展能力

- 第二个游戏引擎适配器
- 图片、字体和 UI 本地化实验
- 游戏内自动化验证

### V1.0：可发布本地化工作台

- 完整导入到导出闭环
- 可恢复任务、翻译记忆和审计日志
- 插件接口与版本兼容策略
- 授权项目的测试补丁构建
