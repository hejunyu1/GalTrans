# ADR 0001：确定性核心与受约束模型

- 状态：已接受
- 日期：2026-08-16

## 背景

视觉小说脚本包含变量、标签、分支、控制代码和特殊编码。语言模型擅长语言理解，但输出不稳定，
也不能证明文件修改在语法和字节层面安全。

## 决定

游戏扫描、解析、标记保护、校验、导出和备份由确定性程序负责。模型只能接收统一中间格式并
返回符合模式的建议。未经结构、标记和语法校验的结果不能进入导出流程。

## 影响

- 早期开发会花更多时间建设解析、校验和测试基础。
- 单个失败任务可以安全重试，不需要重新处理整个项目。
- 模型供应商可以替换，而不会改变引擎适配器。
- 无法确认的语法必须报告给用户，不能静默猜测。
