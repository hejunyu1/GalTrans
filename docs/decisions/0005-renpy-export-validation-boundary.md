# 0005：只在完整可写临时副本中验证 Ren'Py 导出

- 状态：已接受
- 日期：2026-08-18

## 背景

独立导出器已经能生成全新的 `game/tl/<language>` 补丁目录，但文件结构正确不等于 Ren'Py
能够载入和编译它。Ren'Py 8.5.3 的独立 `compile` 会同时尝试重编译 SDK 自带的
`renpy/common`；若从只读安装目录执行，命令可能输出权限异常却仍返回退出码 0。只复制项目、
继续使用原 SDK 可执行文件，无法保持 SDK 安装目录的只读边界。

## 决定

导出验证接收三个相互独立的只读输入：Ren'Py SDK、包含 `game` 的源项目和独立导出根目录。
三者互为祖先或后代时拒绝继续。导出根目录中的所有文件必须是
`game/tl/<language>` 下的 `.rpy`，并拒绝链接、目录联接和其他文件。

验证只在系统创建的唯一临时根目录中进行：

1. 用普通文件复制建立完整、可写的 SDK 副本；
2. 只把输入项目 `game` 下非 `tl` 的 `.rpy/.rpym` 复制到临时项目；
3. 把导出文件按 `game/tl/<language>` 下的相对路径合并到临时项目；
4. 从临时 SDK 执行 `--version`，并对临时项目执行 `lint`；
5. 删除 lint 在临时项目中产生的 `.rpyc/.rpymc`，再从临时 SDK 执行独立 `compile`；
6. 要求每个项目源脚本和翻译脚本都实际生成对应编译文件。

所有项目命令都使用临时存档目录。非零退出码、Traceback、文件或权限异常、空 lint 报告，
以及缺少预期编译文件都使验证失败。验证前后重新计算输入项目源脚本和导出翻译文件的哈希。

允许的验证命令仅为：

```text
<临时 SDK>/renpy.exe --version
<临时 SDK>/renpy.exe <临时项目> lint --savedir <临时存档目录>
<临时 SDK>/renpy.exe <临时项目> compile --savedir <临时存档目录>
```

## 结果

已安装 SDK、输入项目和独立导出目录都不交给可能写入的 lint/compile 进程。SDK 自身编译物、
项目 `.rpyc/.rpymc`、缓存、存档和日志随临时树清理。完整 SDK 复制会增加时间和临时磁盘占用，
但当前优先选择明确、易审阅的隔离边界，不采用会共享底层文件的硬链接或不完整运行时副本。

此验证证明受支持的 source-only 项目与导出翻译能被指定 SDK lint 并独立编译；它不证明译文
覆盖完整、不验证图形启动或显示效果，也不授权处理未获许可的真实游戏。
